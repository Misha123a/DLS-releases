# DLS

Готовые сборки клиента DLS для Windows.

## Скачать

[Скачать DLS для Windows](https://github.com/Misha123a/DLS-releases/releases/latest/download/DLS-Windows.zip)

[Все релизы](https://github.com/Misha123a/DLS-releases/releases)

## Запуск

1. Скачайте `DLS-Windows.zip`.
2. Распакуйте архив целиком.
3. Откройте папку `DLS` и запустите `DDNet.exe`.

Сохраняйте DLL-файлы и папку `data` рядом с программой.

Этот репозиторий предназначен для распространения готовых сборок. Исходный код клиента здесь не размещается. Уведомления об авторах и лицензиях компонентов находятся в `license.txt` и файлах сборки.
